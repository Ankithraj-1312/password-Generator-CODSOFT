# 🔐 CodSoft Internship Project - Password Generator

This project is a **Password Generator** built using **Python** as part of my **CodSoft Internship**.

It allows users to generate strong and random passwords of a desired length, combining uppercase letters, lowercase letters, digits, and special symbols for better security.

---

## ✨ Features
- 🔢 Allows the user to choose the **password length**
- 🔠 Uses a mix of **uppercase, lowercase, digits, and symbols**
- 🎲 Generates a **completely random and secure password**
- 🧠 Demonstrates the use of loops, strings, and Python’s built-in `random` module
- ❌ No external libraries required

---

## 🧰 Tech Stack
- **Language:** Python  
- **Modules Used:** `random`  
- **Concepts Used:** Loops, Strings, Randomization
